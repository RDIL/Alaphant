# Short official Charles names that are real identifiers, not obfuscator output.
#
# The obfuscator emits four-letter names drawn from a small pool, plus a short tail
# (`a_`, `b_`, `b`). Four letters is also a perfectly good length for a real
# identifier -- `read`, `size`, `Mode` -- and case shape alone cannot tell `kmft`
# from `kmft`-shaped English (`fluh`, `sesd` and `unek` are obfuscator output;
# `data`, `host` and `tree` are not). So short names default to OBFUSCATED and this
# file is the exception list.
#
# Defaulting that way is deliberate. Mistaking a readable name for an obfuscated one
# costs a needless `field_N`/`method_N` placeholder, and the identity bootstrap gives
# it its real name back in the `named` namespace anyway. Mistaking an obfuscated name
# for a readable one leaks a name that churns on every Charles release into the
# `intermediary` namespace, which is the one thing the three-namespace scheme exists
# to prevent.
#
# Names of five characters or more are always treated as readable and never need
# listing here.
